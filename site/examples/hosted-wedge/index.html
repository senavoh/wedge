01

Verdict

KILL

The premise holds: GummySearch stopped taking payments on Nov 30, 2025 after failing to get a commercial Reddit Data API license, and it shuts down Dec 1, 2026. Reddit now requires approval for new API apps. But the exact wedge, no-Reddit pain research pitched at GummySearch refugees for $29/mo, is already on sale (GripeFind). Free substitutes (ChatGPT Deep Research, an MIT-licensed MCP with the same sources, Wedge itself) cover most of the rest. Buyer pain after the shutdown is thin: launches in this category get 0 to 2 HN comments.

07

Pricing and cost

Pricing

Don't launch a $19-29/mo subscription. If you test anything, test a one-off report.

The monthly price slot is taken by GripeFind at $29. The only large paying base found buys one-off reports (c8, c9).

Competitors: Free (F5Bot, ValidatorAI) to $29-$99/mo (GripeFind, Syften, Reddinbox); $9-$129 one-time (DimeADozen)

08

7-day test

One experiment, one pass bar. Run it before writing code.

Before writing code, post one free verified Wedge report on HN and Indie Hackers with a $19 'run one for my idea' button.

Pass bar (7 days): 5 paid orders in 7 days

  • Day 1: run Wedge on 3 ideas from public Ask HN threads and publish the reports
  • Day 2-6: offer paid runs in the threads where founders ask for validation
  • Day 7: count orders against the pass bar

Kill it if

  • Under 5 paid orders in 7 days
  • Most buyers ask for Reddit data first
