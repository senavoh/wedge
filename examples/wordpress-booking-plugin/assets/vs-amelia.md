# SteadySlots vs Amelia (draft comparison page)

> **Before you publish:** every SteadySlots line in `[brackets]` is a promise. Publish it only once it's true. The Amelia facts are from Amelia's own pricing page and help center (fetched 2026-10-18) and from public WordPress.org reviews. Amelia's annual prices are geo-based and didn't render in the fetched page text, so check them in a browser before quoting a number.

## The short version
Amelia has a slick front end and a long feature list (90,000+ active installs, rated 92/100 from 790 ratings on WordPress.org). SteadySlots is for small salons, barbers, tutors and therapists who want booking that **keeps working through updates**, **support that answers**, and a **move off Amelia that doesn't lose appointments**.

## Side by side

| | Amelia | SteadySlots |
|---|---|---|
| Pricing | Four tiers (Starter, Standard, Pro, Elite). "Pricing is geo-based: the final price depends on your location…" (Amelia help center) | [$79/yr, one plan, every feature, shown in USD] |

Destructive migrations never run automatically] |
| Support | Reviewers report waits of days to weeks, e.g. "They are supposed to get to us within 24 hours, I wait for weeks…" (`facing-an-issue-since-2-months-_`, ~2026-08) | [Named developer, first reply within 1 business day, Mon–Fri] |

| Developer hooks | A reviewer: "Hooks? Forget about it. Code documentation – non-existent." (~2023). Amelia's Pro tier lists a REST API | [Documented actions and filters] |
| Moving your data | Third-party tools already migrate Amelia data: Sugar Calendar Bookings, the BookingPress Migration Addon, and PW Amelia Migration (each vendor's own page) | [Free done-for-you migration from Amelia with a before/after count] |

## Fair notes
- Amelia sells events, packages, resources and a mobile app. SteadySlots doesn't do events.
- Several reviewers also praise Amelia's UI, and some say its support resolved their issue in the end ("great support but slow initial response").
