# Shelf Sorted vs Shopify's built-in purchase orders (draft)

Shopify's native purchase orders are free and built in. For some shops they're enough.

What merchants report when they try them for real orders:
- "The PO feature in shopify is brutally inadequate. Using it takes more than triple the time to place an order." [e7]
- "The native Shopify PO workflow feels much more manual, especially when you are ordering multiple SKU's." [e8]
- Vendors have to be re-created as suppliers [e15], and suppliers can't be exported from Stocky [e17].

**What we do:** keep native POs if they fit you. Then we build the supplier list from your vendors, create reorder templates, and get labels printing. If native POs don't fit, we set up a free or cheap app instead, and we'll tell you which one and why.
