# Competitors (quick)
Premise check: B2B Peppol e-invoicing mandatory since 1 Jan 2026 for Belgian-established VAT entities, incl. small-enterprise-exempt (e1-e3); 3-month tolerance Q1 2026, now over (e4). Hermes (free govt tool) shut 31 Dec 2025 (e7-e8). FPS list includes free/low-cost tools (e5); 120% deduction for invoicing subscriptions 2024-2027 (e6). 89% of VAT-registered firms already on Peppol (e10, e11).

Crowded/empty:
- Every price point from €0 to €19/mo is already occupied by a Woo plugin with a certified Access Point.
- Receiving is covered free by accounting tools (Accountable, Peppyrus); WP shops don't receive in Woo.
- Install bases are tiny (0-100) for all newcomers: demand for a Woo-native plugin looks thin, or buyers use their accounting tool instead.
- Under-served: buyer-data capture (VAT no. / Peppol ID lookup) and pre-send validation; GoRoute and Peppol Plugged already claim parts of it.
